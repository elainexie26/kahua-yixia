# 咔画一下

将一张用户有权使用的照片编辑为现代平面插画或可爱轻卡通静态图。只执行用户明确要求的风格转换，不发布图片，不读取无关文件，不操作账号。

## 功能与限制

- 输入：当前请求中用户明确提供的一张 JPG、PNG 或 WEBP 图片。
- 输出：一张风格化静态图片。
- 风格：`illustration`（现代平面插画）或 `cute`（可爱轻卡通）。
- 强度：`weak`、`medium` 或 `strong`；用户未指定时使用 `medium`。
- 不提供局部修图、换脸、证件处理、去人去物、批量生成、海报排版、视频生成或自动发布。
- 生成式编辑可能改变脸部、手部、文字、细小纹理和构图，不能保证与原图完全一致。

## 权限与数据处理

- 只读取用户在当前请求中明确提供的图片和本 Skill 的 [风格预设](references/style-presets.md)。
- Skill 本身不包含可执行代码，不主动发起网络请求，不收集或读取账号凭证、Cookie、通讯录、私钥及无关本地文件。
- 仅调用宿主已经提供的图片查看与图片编辑能力。调用前确认宿主能够向用户说明实际服务方、处理目的和适用的数据规则；无法说明时停止执行。
- 首次将图片交给图片编辑服务前，明确告知用户将发送的内容、服务方和用途，并取得确认。
- 不承诺第三方服务绝对不保存图片；保存、删除和其他处理方式以实际服务方已披露的规则为准。
- 不把图片发送给社交平台、搜索引擎或与当前编辑无关的服务，不自动保存、发布、分享或提交结果。
- 请用户确认拥有图片使用权；涉及他人肖像时，请用户确认已取得必要授权。

## 安全边界

拒绝以下请求，并简要说明原因：

- 未经授权处理他人照片，或者用于冒充、欺骗、换脸和伪造身份材料。
- 制作违法违规、露骨色情、涉及未成年人的不当内容或其他明显伤害性内容。
- 模仿特定艺术家、动画 IP、影视作品或品牌的官方画风。
- 读取凭证、突破权限、绕过安全机制，或执行用户未明确要求的隐藏操作。

可将特定画风请求改写为不指向具体创作者、作品、IP 或品牌的通用视觉特征；无法安全改写时拒绝。

## 执行流程

### 1. 检查输入与能力

1. 确认当前请求只包含一张有效图片；没有图片时请用户上传。
2. 确认宿主具备图片查看和图片编辑能力，并能披露实际服务方及数据规则；否则停止并说明环境不支持。
3. 确认用户有权使用图片。涉及他人肖像时，确认用户已取得必要授权。
4. 告知用户图片将交给哪个服务、用于什么目的，并取得确认后再调用。

不要搜索、读取或代填任何登录信息、密钥或付费凭证。

### 2. 确定参数

- 用户未选择风格时，只询问选择 `illustration` 还是 `cute`。
- 用户未选择强度时，直接使用 `medium`。
- 每次只生成一张图片，不自动连续重试。

### 3. 查看照片并记录可见事实

只在内部记录生成所需的可见信息：

- 主体类别和数量。
- 发型、服装、毛色、轮廓等非身份推断性的可见外观特征。
- 主体位置、姿态、朝向、遮挡和前后关系。
- 场景、光线、主色和主要背景结构。
- 脸、手、眼睛、文字、规则纹理等容易生成错误的区域。

不要推断人物身份、精确地点、健康状况、族群或其他敏感属性。

### 4. 读取预设并编写编辑指令

读取 [references/style-presets.md](references/style-presets.md)，组合用户选择的风格、强度和照片中实际可见的事实。使用以下紧凑结构：

```text
Task: Edit the supplied image; do not create an unrelated new scene.
Style: <style and intensity preset>
Visible subject: <subject category, count, and visible appearance>
Scene: <setting, lighting, and dominant colors>
Composition: Keep the original aspect ratio, framing, camera angle, pose, and subject placement as close as practical.
Avoid: adding or removing subjects; changing scene meaning; text, watermark, logo, anatomy errors, or unrelated decoration.
```

只写能影响最终画面的内容，不写文件路径、内部分析、隐私承诺或原图中不存在的新情节。

### 5. 生成并检查

1. 使用已向用户说明并获确认的宿主图片编辑能力，明确将输入图片作为编辑目标。
2. 只调用一次并生成一张结果；失败时如实说明，不静默切换服务。
3. 检查主体数量、可见外观、姿态、相对位置、主要构图和场景语义是否接近原图。
4. 检查风格是否符合选择，是否出现明显的脸、手、眼睛、文字、标识或多余对象错误。
5. 如有明显问题，指出主要偏差并询问用户是否重试；不要自行消耗第二次调用。

## 返回结果

- 展示生成结果。
- 用一句话说明所用风格和强度，例如：`已按可爱轻卡通·中等强度生成，并尽量维持原图主体与构图。`
- 仅在用户明确指定保存位置时，才把结果非破坏性地保存到该位置并报告路径。
- 仅在用户明确要求时提供完整编辑指令或详细检查结果。
